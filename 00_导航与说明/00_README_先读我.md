# 清源 · 先读我（README）

> 版本：v1.0 纯净首版 ｜ 建议先读本文件

## 一、这是什么

清源是一个"研究员级"通用研究 Agent。你只需说清"我要什么"，它会像研究员一样完成：**开题 → 取证 → 核验 → 综合 → 交付 → 复盘**。

## 二、目录怎么用

| 目录 | 用途 | 你要做什么 |
|---|---|---|
| `00_导航与说明` | 本文件 | 先读 |
| `01_内核_只读` | 清源的大脑（SOP + 角色提示词） | 只读，别改 |
| `02_知识库` | 行业插件：已审核主库 / 待审区 / 资产库 | 按需查看 |
| `03_产物` | 你每次任务的成果归档 | 在这里找成品 |
| `04_版本归档` | 版本快照，v1.0 是纯净起点 | 出问题可回档 |
| `05_一键启动` | **双击即用的本地 Agent** | 首次①安装环境，之后②启动 |

## 三、怎么开始（推荐：一键启动）

**最省事**：打开 `05_一键启动`，第一次双击 `①安装环境.bat`，以后双击 `②启动清源.bat`，浏览器里直接和清源对话（首次需在「设置」里配置模型后端，详见该目录《启动器说明》；没有 Key 也能用"桥接模式"）。

不想配置，也可以像跟帮手说话："**我想做个 XX / 我想研究 XX**"——不用专业、不用完整。

**换电脑 / 分享给他人 / 让模型自再生**：详见《清源分发与再生说明》——把清源包放进模型可访问的工作文件夹，让模型读 `000_AI请先读我.md` 即可。

## 四、你只做三件事

1. 说清要什么、给谁用；
2. 看着选项/实物，**选 / 点头 / 说"不对"**；
3. 不满意就喊停。

## 五、三个护身符（随时可用）

- "**停**"——暂停、改主意；
- "**我不懂，说人话**"——让它解释；
- "**你确定吗？来源呢？**"——让它证明、给出处。

## 六、要警惕

它有时会很自信地给错（尤其数字、股价、政策）。关键数字让它给来源、取数时间；它内部有查验官会复核，你有疑问也尽管质疑。

## 七、一句话记住

**你负责说要什么，它负责怎么做到；你随时能不能决。**
